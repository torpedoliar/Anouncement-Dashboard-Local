<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Stored HTML (server-sanitized) -> dangerous own innerHTML in a client island | The public renderer mounts markup that was sanitized on-write; the hydrator must NOT re-introduce unsanitized execution or render untrusted strings into href/src of active elements |
| Viewer -> external PDF URL (data-src) | The object/iframe loads a URL that may be cross-origin (external CORS); the page must degrade to a fallback link, never to auto-tab |
| Reader (untrusted user) -> Fullscreen / Download buttons | User-initiated browser APIs; must stay explicit-click-only and not auto-open content |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-03-RENDER | Tampering | ArticleContent dangerouslySetInnerHTML + PdfInline object/iframe data | high | mitigate | Markup is server-sanitized (12-01) before storage; hydrator only reads div[data-pdf]/data-src/data-filename attributes and never builds URLs from names or writes attacker-controlled strings as active-element URLs; the 12-01 URI regex already strips unsafe schemes from data-src |
| T-12-03-POPUP | Spoofing | Fullscreen fallback | medium | mitigate | The only tab-opening path fires on explicit click AND is gated by fullscreen-API unavailability; no automatic tab/window open anywhere on the reader path (SPEC prohibition, resolved) |
| T-12-03-XFRAME | Tampering | external PDF iframe/object | medium | mitigate | Cross-origin content that cannot render degrades to the in-viewer fallback paragraph + download link (D-08); X-Frame-Options: SAMEORIGIN middleware untouched — same-origin `/api/uploads` iframes remain allowed |
| T-12-03-CLIP | Information disclosure (layout) | .prose-santos max-width 72ch | low | accept | Cosmetic: viewer breakout via .pdf-viewer max-width:none is an additive CSS row; a failure of the breakout clips width only, never leaks data |
| T-12-03-SC | Tampering | npm installs | low | accept | No new dependency (createRoot from already-installed react-dom/client) |
