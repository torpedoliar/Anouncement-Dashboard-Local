Ground-truth extracted from the repo 2026-08-17 (do not re-derive):

From lib/validation-schemas.ts (current, empirically verified with node against installed isomorphic-dompurify):
- `sanitizeHTML(html: string): string` — DOMPurify config `ALLOWED_TAGS: [..., 'div', 'span', 'hr']` (NO generic media tags), `ALLOWED_ATTR: ['href','target','rel','src','alt','title','width','height','class','id','style','frameborder','allowfullscreen','allow']`, `ALLOW_DATA_ATTR: false`.
- Empirical proof (run against installed package): adding `data-pdf`, `data-src`, `data-filename` to `ALLOWED_ATTR` while keeping `ALLOW_DATA_ATTR: false` PRESERVES those three data attrs, and DOMPurify's default URI regex STILL strips `data-src="javascript:..."` and `data:text/html;base64,...` and removes any injected generic media/onerror markup. Do not loosen ALLOW_DATA_ATTR or add a URI allowlist.
- Module imports are `zod` + `isomorphic-dompurify` only — node/tsx-importable without env/DB (verified).

From app/api/uploads/[...path]/route.ts:
- `MIME_TYPES: Record<string,string>` keyed by lowercase extension; default `application/octet-stream`.
- Guard: rejects any segment `=== ".."` , `=== "."`, or `includes("\\0")` before touching the FS; `resolve(UPLOAD_DIR, ...path)` + prefix check `filepath !== UPLOAD_DIR && !filepath.startsWith(UPLOAD_DIR + sep)`.
- Response sets `Content-Type`, `Cache-Control: public, max-age=31536000, immutable`, `Accept-Ranges: bytes`.

From app/api/media/route.ts (POST):
- Constants `IMAGE_TYPES`, `VIDEO_TYPES`, `MAX_IMAGE_SIZE 10MB`, `MAX_VIDEO_SIZE 100MB`.
- POST contract: `getServerSession(authOptions)` (401 if null) -> `formData.get("file")` -> type/size validation (400) -> `mkdir` -> `writeFile` into `public/uploads/<folder>` -> `prisma.mediaLibrary.create({ filename, url, mimeType, size, alt, siteId })` -> 201 with `{...media, originalSize, compressedSize, savedPercent}`.
- Video branch is the template to clone: raw buffer, `filename = `video_${Date.now()}_${random}.mp4``, no compression.
