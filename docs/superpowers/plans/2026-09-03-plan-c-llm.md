# Plan C — LLM Andal + Privasi Keras Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** LLM menjadi analis bukti yang andal (JSON valid, reasoning ternormalisasi, voting transparan) dengan guard privasi yang membatalkan pengiriman sensitif.

**Architecture:** Perluas `lib/portal-llm-analyze.ts` (kontrak ketat, konteks bukti, budget per model, `assertSafePrompt` guard, `logAudit` tiap panggilan) + kolom `maxTokens` di `PortalAiSettings` + voting di `detect-fields`. Tanpa dependensi baru.

**Tech Stack:** TypeScript, Prisma, `logAudit` dari `lib/audit.ts`, `npx tsx scripts/test-llm-analyze.ts` (tambah kasus, tanpa hapus kasus lama).

## Global Constraints

- Syarat keras Seksi 5 spec: nilai input, token, cookie, kredensial, data HRIS, query URL, HTML mentah TIDAK BOLEH keluar. Test penerimaan: payload berisi NIK/email/token palsu HARUS dibatalkan guard.
- Tiap pemanggilan LLM dicatat via `logAudit` (waktu, model, ukuran payload — tanpa isi).
- Ollama/lokal harus tetap jalan: `response_format` hanya dikirim untuk baseUrl non-lokal.
- Tiap task diakhiri commit pesan Indonesia.

- [ ] **Step 3: Write minimal implementation**

Di `lib/portal-llm-analyze.ts`, tambah sebelum `callChatCompletion`:

```ts
const SENSITIVE_PATTERNS: Array<{ label: string; re: RegExp }> = [
    { label: "nilai input", re: /\bvalue\s*=\s*["'][^"']+["']/i },
    { label: "email", re: /[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}/ },
    { label: "NIK/nomor digit", re: /\b\d{8,16}\b/ },
    { label: "token panjang", re: /\b[A-Za-z0-9+/=]{32,}\b/ },
];

/** Batalkan pengiriman bila payload mengandung data sensitif. Throw = tidak dikirim. */
export function assertSafePrompt(payload: string): void {
    for (const { label, re } of SENSITIVE_PATTERNS) {
        if (re.test(payload)) {
            throw new Error(`Payload LLM dibatalkan: terdeteksi ${label}. Bersihkan pruner sebelum mengirim.`);
        }
    }
}
```

Tambah `assertSafePrompt` ke `__llmTestables`.

Di `callChatCompletion`, tambah parameter `useJsonMode: boolean` dan bila true sertakan `response_format: { type: "json_object" }` di body. Tentukan `useJsonMode` di `analyzeLoginWithLlm`/`testAiConnection` sebagai `!/localhost|127\.0\.0\.1|ollama/i.test(config.baseUrl)`.

Normalisasi reasoning: setelah `extractChatContent`, bila `safeJsonObject(content)` null TAPI content berasal dari reasoning fallback, biarkan note eksisting yang bicara (tidak perlu kode baru — pastikan `analyzeLoginWithLlm` memanggil `assertSafePrompt(userPrompt)` SEBELUM `callChatCompletion`, dan pada throw return `{ analysis: null, note: "AI: pengiriman dibatalkan guard privasi: ..." }`).
